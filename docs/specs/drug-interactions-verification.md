# Drug Interaction Checker — задача на верификацию

> **Статус:** 🔴 BETA, требует верификации
> **Создано:** 2026-05-05
> **Приоритет:** P0 для коммерческого запуска, P1 для бесплатной версии
> **Оценка:** 40-60 ч клин-фармаколога

## Контекст

Phase 1 чекер взаимодействий (`/drugs`) выкачен в коммите `c91b433` с
**62 препаратами** и **83 парами взаимодействий**. Контент составлен
автоматически на основе открытых медицинских источников (UpToDate
Lexidrug, Stockley's 12th, ESC/AHA guidelines, FDA, EMA SmPC,
DrugBank).

**Каждая пара НЕ прошла ручную верификацию клин-фармакологом.**

Я — AI-помощник, я не имею доступа к UpToDate в реальном времени,
не читал каждый цитированный источник целиком, не сверял каждую
числовую характеристику (например, «↑ концентрации в 2-3 раза»).

Использовал свои внутренние знания + структурированные шаблоны
из открытых баз. Это даёт результат уровня «уверенный студент-
ординатор после прочтения учебника» — но не уровень клин-фармаколога
с подписью.

## Что нужно сделать

### Задача 1 — Аудит существующих 83 пар

Клин-фармаколог проходит по каждой паре в `data/drug-interactions.json`
и для каждой проверяет:

1. **Severity** — соответствует ли реальной классификации?
2. **Mechanism** — корректно ли описан механизм (CYP, Pgp, plasma binding, QT)?
3. **Effect** — реально ли «↑ МНО в 1.5-2 раза» или там другая величина?
4. **Management** — практически применимо? Соответствует актуальной
   редакции ESC/AHA/Минздрава? Не противоречит инструкции производителя?
5. **Sources** — действительно ли в указанном источнике есть эта рекомендация?

После проверки — обновить пару в JSON и поставить
`"verified_by": "clinical_pharmacologist"` + `"verified_at": "YYYY-MM-DD"`
+ `"verified_by_name": "Имя Фамилия"` (опционально).

### Задача 2 — Добавить недостающее

В Phase 1 покрыты только топ-сценарии. Не покрыто:

- Онко-препараты (цисплатин, доксорубицин, тамоксифен, иматиниб, ...)
- Иммуносупрессанты (циклоспорин, такролимус, азатиоприн, метотрексат)
- Антипсихотики (галоперидол, рисперидон, кветиапин, клозапин)
- Противосудорожные (карбамазепин, фенитоин, вальпроат, ламотриджин)
- ВИЧ-терапия (ритонавир, эфавиренз, долутегравир)
- Препараты-импорты редкие в РФ (тикагрелор-зона vs прасугрел-зона)
- Pediatric-specific dosing нюансы

### Задача 3 — Контроль качества

- Кросс-референс: каждая пара должна быть подтверждена **минимум 2 источниками**
- Эскалация: если источники противоречат — выбрать наиболее свежий или
  пометить пару как `"severity": "disputed"` с пояснением
- Версионирование: при добавлении/изменении пары — bump
  `data/drug-interactions.json` `version` (semver)

### Задача 4 — Аккуратность UI

- BETA-баннер на странице чекера (уже добавлен)
- При отображении неверифицированной пары — мелкий значок «AI-сгенерировано,
  не верифицировано»
- При отображении верифицированной — значок «Проверено клин-фармакологом»
- Полный аудит-бар: «верифицировано: X/Y пар (Z%)»

## Кто делает

**Кандидаты на верификацию:**
- Клин-фармаколог с активной практикой в стационаре (приоритет: ИКБ № 1, ФГБУ НМИЦ)
- Преподаватель клин-фармакологии медицинского вуза (Сеченовский, РНИМУ им. Пирогова, ПМГМУ)
- Член ассоциации клин-фармакологов России (АКФР) или РОТЭХ

**Ставка ориентировочная:** 1500-3000 ₽/час (коммерческие тарифы клин-фармаколога) × 40-60 ч = **60-180 тыс ₽** разово.

## Когда делать

- **До коммерческого запуска** (продажа подписок, B2B-договора с
  клиниками) — обязательно. Без верификации высокий юр-риск
  ответственности при клин-инциденте.
- **Для бесплатной образовательной версии** — желательно, но не
  блокирует. BETA-дисклеймер юридически защищает.

## До верификации
