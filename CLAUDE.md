## Стандарты продукта

### PDF-скачивание таблиц
- **Только справочные таблицы** имеют кнопку «Скачать PDF» — те, что люди могут захотеть распечатать / держать под рукой.
- Детекция (в `TabbedLessonViewer.tsx` → переопределение `<table>`) — **ИЛИ одно из**:
  - Заголовок колонки содержит одно из ключевых слов:
    - **Словари:** корень, префикс, суффикс, термин, аббревиатура, обозначение
    - **Нормы и значения:** норма, референс, диапазон, показатель
    - **Препараты:** препарат, дозировка, доза, лекарство, действующее
    - **Формулы / классификации:** формула, классификация, стадия, шкала, балл, градация
    - **Симптомы / диагнозы:** симптом, синдром, критерий, признак, этиология, патогенез, заболевание, болезнь, диагноз
    - **Анатомия / физиология:** орган, система, функция, роль, структура, ткань
    - **Химия / физика:** вещество, элемент, реакция, соединение, pH
    - **Методы и процессы:** метод, процесс, применение, лечение, терапия
    - **Единицы и размеры:** единица, размер, масштаб
  - ИЛИ таблица «большая» — **3+ колонки И 4+ строки** (крупные справочные таблицы).
- Маленькие таблицы (2 колонки / 2–3 строки) без ключевых слов — кнопку **не получают**.
- Реализация генерации — `jsPDF` + `html2canvas` (lazy-loaded в `components/course/DownloadableTable.tsx`).
- **Почему html2canvas, не autoTable:** встроенные шрифты jsPDF не поддерживают кириллицу. html2canvas рендерит DOM с реальными шрифтами проекта (Montserrat, JetBrains Mono) → кириллица корректна + визуал совпадает с сайтом.
- Алгоритм:
  1. Клонируем таблицу в offscreen-контейнер (`position: absolute; left: -99999px`) со стилями Bordik (шапка «Bordik» + дата, заголовок, table с зеброй, футер «Powered by Bordik»).
  2. `html2canvas` с `scale: 2` (Retina) → canvas.
  3. Разбиваем canvas на A4-страницы через вертикальный слайсинг, вставляем в jsPDF как PNG.
  4. `pdf.save(filename.pdf)` — реальный download, не print dialog.
- Реализация кнопки — `components/course/DownloadableTable.tsx`. Кнопка **снизу справа** под таблицей.
- При клике: открывается новое окно с чистой вёрсткой (шапка «Bordik» + дата + таблица + футер «Powered by Bordik») и автоматически триггерится `window.print()`. Пользователь сохраняет PDF стандартно через браузер.
- Заголовок PDF формируется из заголовков колонок (первые 3 через « / »).

**Правило при добавлении уроков:** если создаёшь таблицу, которая по смыслу является справочником — используй один из ключевых заголовков из списка выше (например `| Корень | Значение | Примеры |` вместо `| A | B | C |`). Тогда кнопка появится автоматически.

### Цветовая палитра
- Карточки: `#F5F6F8`, hover `#F0F2F5` / `#EFF1F4`
- Активные элементы сайдбара: `#E2E4EA`
- Фон сайдбара: `#F0F1F5`
- CTA кнопки: чёрный `#1A1A1A`, hover `#000000`
- Акценты тестов: зелёный `#22C55E`, красный `#F87171` (не `#10B981`/`#EF4444` — они слишком кричащие)
- Бордеры и разделители: `#EEF0F3` / `#E2E4EA`

### Типографика
- Display: `var(--font-display)` (Montserrat)
- Mono: `var(--font-mono)` (JetBrains Mono) — для лейблов, бейджей, ID
- Эмодзи в UI: через `components/ui/EmojiOrFlag.tsx` (флаги через Twemoji CDN, остальное — нативно).

### Анимации
- Основной easing: `cubic-bezier(0.22, 1, 0.36, 1)` (ease-out-quart)
- Hover транзишны: 180–350ms на background (без translate для простоты)
- Mount карточек: 250ms fade+slide через framer-motion
- Сворачивание/раскрытие: CSS grid `gridTemplateRows: 0fr ↔ 1fr` (не `height: auto` — это laggy)

### Дропдауны и инпуты
- Все селекты через `components/ui/Dropdown.tsx` (единый стиль, группировка, поиск, сворачиваемые категории)
- Поля ввода: серый фон `#E2E4EA` / `#EEF0F3`, при фокусе чуть темнее — **без** громких бордеров и колец

## Архитектура контента

- `lib/content/course-100-1.ts` — source markdown всех тем курса
- `preprocessContent` в `TabbedLessonViewer.tsx` конвертирует:
  - 1-колоночные таблицы с префиксом `ℹ/⚠/📷/✓/🎯/💡` → блок-каллауты
  - `\|` внутри каллаутов → `|`
  - Строки вида `X = Y | A = B` → bullet list
  - Ключевые слова (`Пример:`, `Значит:`, `Итог:`...) → bold
  - Em-dash `—` → `-`

- Темы курса делятся на вкладки (`Биология`, `Химия`, `Физика`, ...) через `# Тема N` разделители
- Специальные вкладки: `Самопроверка` (kind `selfcheck` → `InlineQuiz`), `Тесты` (kind `tests` → `TestPanel`)

## Навигация

Сайдбар группы:
- **Основное**: Главная (новостной feed), Обучение
- **Сервисы**: Инструменты (калькуляторы, справочники)
- **Аккаунт**: Статистика, Профиль

Поиск ищет:
- Пункты навигации (по синонимам)
- Курсы (через `searchCourses` в `lib/curriculum.ts`), разделены на «Доступные» и «Скоро будут доступны»

## i18n

- 4 языка: `ru`, `en`, `kk`, `uk` (flag codes)
- Ключи в `lib/i18n.ts` как flat dict
- `useT()` хук, `useLang()` для текущего кода
- Язык хранится в `userLanguage` в Zustand store (персистится)
